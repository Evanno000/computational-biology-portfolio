01 / BIOLOGICAL BACKGROUND

Research context

QUA1 (QUARTET 1), associated with locus AT3G25140 in Arabidopsis thaliana, is linked to plant cell-wall biology and homogalacturonan-related processes.

This project uses the QUA1 transcript as a nucleotide sequence query to explore sequence similarity against entries in the NCBI nucleotide database.

02 / OBJECTIVES

Project objectives

  • Retrieve a nucleotide transcript from a biological database.
  • Perform nucleotide sequence similarity searching using BLASTn.
  • Examine sequence identity, alignment length, query coverage and bit scores.
  • Process BLAST results using Python.
  • Generate structured CSV output and visualisations.
  • Interpret the results within their biological and computational limitations.
03 / METHODOLOGY

Analytical workflow

01

Transcript retrieval

Retrieved the QUA1 transcript from the NCBI Nucleotide database using accession NM_113418.5 and stored the sequence in FASTA format.

02

BLASTn search

Submitted the transcript to NCBI BLASTn using the nucleotide database, a highly similar sequence search and an Arabidopsis thaliana organism restriction.

03

Results retrieval

Downloaded the BLAST hit table in tabular format containing sequence identity, alignment length, coordinates, E-values and bit scores.

04

Python processing

Used Biopython to read the query FASTA and Pandas to process the BLAST table, convert numerical columns, sort hits and calculate an estimated query coverage value.

05

Visualisation

Generated comparative horizontal bar plots illustrating percentage identity and estimated query coverage among selected non-self hits.

06

Data export

Exported the processed BLAST dataset to CSV for reproducibility and further analysis.

07 / INTERPRETATION

Biological and computational interpretation

The BLAST search identified nucleotide sequences showing strong similarity to the QUA1 transcript. Several hits demonstrated high sequence identity over substantial portions of the query sequence.

Identity and coverage

Percent identity describes the proportion of identical nucleotide positions within an alignment, whereas query coverage describes how much of the query sequence is represented by the alignment.

The second hit, AY099574.1, showed 100% identity over approximately 83.76% of the query according to the coordinate-span estimate used in this analysis.

Self-match

The query sequence itself appeared as the top BLAST hit with 100% identity and full query coverage. This is expected because the sequence is present in the search database.

E-value

BLAST displayed E-values of 0.0 for several top hits. This reflects values below the display precision of the interface rather than a mathematically literal zero.

Biological meaning

Sequence similarity supports relationships between nucleotide sequences but does not independently establish biological function. Interpretation requires additional biological evidence and contextual analysis.

08 / LIMITATIONS

Analytical limitations

  • The search was restricted to Arabidopsis thaliana.
  • The nucleotide database changes over time, meaning future searches may produce different results.
  • Query coverage was estimated from query-coordinate span and may differ from reported coverage for alignments involving gaps or multiple segments.
  • The query's own database match is expected and is excluded from the comparative plots.
  • Sequence similarity alone does not confirm biological function.
  • This project represents a computational sequence similarity analysis rather than an exhaustive functional investigation.

Interpretation caution: The coverage values shown in the Python analysis are coordinate-span estimates. They should not be treated as exact BLAST alignment coverage in cases involving complex alignments.
